PMPF Updater

Sistema que automatiza a atualização do catálogo de preços PMPF (usado no cálculo de ICMS por substituição tributária) da SEFA-PA. Extrai tabelas de PDFs de portarias, compara com o catálogo em Excel e apresenta as mudanças numa interface web para revisão e aprovação, eliminando um processo antes feito manualmente, linha a linha.

  • Python
  • Streamlit
  • Camelot
  • Pandas

Projeção de Arrecadação de Impostos do Pará

Modelo de séries temporais com Prophet para projetar 12 meses de arrecadação dos principais impostos do Pará (ICMS, IPVA, ITCD), com dados públicos da SEFA-PA. Validação com Walk-Forward e Rolling Window, tuning via Grid Search, e erro de apenas 4% (MAPE) na previsão de ICMS.

  • Python
  • Prophet
  • Scikit-learn
  • Pandas
